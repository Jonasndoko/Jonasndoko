# Passage de GESTSCO au web : avancement

Principe : la logique métier (droits, paiements, notes, bulletins, audit...) est réutilisée telle quelle ; on réécrit seulement les écrans Tk en pages web, module par module.

Rien n'est supprimé : « Retirer » exige un motif, masque le document, le fichier reste dans la base ; case « Afficher les documents retirés ». Droits sur « Secrétariat » : Lecture = rechercher, consulter un dossier, ouvrir ; Modification = classer ; Suppression = retirer (non accordé par défaut à la secrétaire : à donner dans le Gestionnaire d'accès). Code : convocations.py, tests : test_convocations.py. **Direction des études, 7e fonctionnalité « Passage en classe supérieure » (web, v1.1)** : à la fin de l'année, la Directrice des études affecte les élèves à l'année suivante : les élèves qui ont réussi (résultat annuel « ADMIS(E) » des bulletins) passent dans la classe supérieure (7ème > 8ème > 1ère > 2ème > 3ème > 4ème humanités, même division, même option en humanités) ; ceux qui ont échoué restent dans la même classe (inscrits « Redoublant ») ; ceux dont le résultat est en attente ne sont pas traités ; la 4ème réussie met fin aux études. **8ème : l'option est choisie par l'élève et saisie à sa place par la Direction des études** (classe de 1ère humanités d'accueil, élève par élève ou pour tous les élèves sans choix ; jamais d'option d'office ; saisie possible avant la fin de l'année).
